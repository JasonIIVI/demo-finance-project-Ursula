# demo-finance-project-Ursula

A lightweight finance dashboard prototype with a Bloomberg-terminal-inspired UI focused on company stocks, bonds, and futures.

## Features

- Company stock watchlist with price action, volume, and directional signals.
- Bond monitor for Treasury and corporate spread tracking.
- Futures board covering equity index, energy, and rate contracts.
- Financial-wire-style news feed plus X/Twitter signal monitoring cards.
- Selectable alert presets so users can pin only the catalysts they want to follow.

## Run locally

Because the project is static HTML/CSS/JS, you can open `index.html` directly in a browser or serve the directory with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
